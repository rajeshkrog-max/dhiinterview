# Manas Darpan

An 18-question, click-through student entry assessment. It reads Prakriti (Vata / Pitta / Kapha), Manas (Sattva / Rajas / Tamas) and chakra balance through indirect, everyday questions, then shows a reflection report.

## Run it

**Easiest:** double-click `index.html` to open it in Chrome or Edge. It needs an internet connection for the fonts only.

**On localhost** (optional), from this folder:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## During the interview

- Share your browser window, then click **Full screen**.
- Keys `1`–`4` choose an answer, `→` or `Enter` goes next, `←` goes back.
- **Notes for the interviewer** on the report page stays collapsed. Open it only if the student can't see your screen, or after the session.
- **New student** resets for the next person.

## About the percentages

The starting percentages are indicative estimates. Each completed session adds that student's answers to the counts, which are saved in your browser. Always present from the same computer and browser so the numbers keep building into real figures from your own students.
